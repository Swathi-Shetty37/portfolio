## 🎨 Design System & Aesthetic Directives

- **Design Theme:** Modern Developer Portfolio
- **Color Palette:** Royal Indigo & Electric Cyan (Primary Indigo `#4F46E5`, Electric Cyan `#06B6D4`, Deep Obsidian Canvas `#090D16`)
- **Default Appearance:** Light Theme (with a one-click Dark Mode toggle saved to `localStorage`)
- **Typography:**
  - Headings: [Outfit](https://fonts.google.com/specimen/Outfit)
  - Body: [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans)
- **Motion & Micro-interactions:** Subtle animations, floating pills, smooth hover elevations, and `@media (prefers-reduced-motion)` accessibility support.
- **Hero Presentation:** Text-Focused Introduction highlighting authentic student background, location badge, and direct call-to-actions.

---

## 🛠️ Features & Interactive Components

1. **Sticky Navigation Bar:** Glassmorphism backdrop blur with responsive drawer navigation for mobile devices.
2. **Light / Dark Mode Switcher:** Instant theme switching with preference persistence in browser `localStorage`.
3. **Skill Expertise Indicators:** Verified skill badges and visual progress meters (`Basic` and `Beginner` tiers) across Core Languages, Web Development, Databases, Cloud, and Data Science.
4. **Interactive Skill & Project Filtering:** Filter competencies by domain (Core Languages, Web & Frontend, Backend & DB, Cloud & Tools).
5. **Interactive Resume Modal & Print Engine:** A dedicated, formatted resume document viewer with a native `window.print()` / "Save as PDF" function.
6. **One-Click Clipboard Copy:** Instant copy for email and phone number with feedback toast notifications.
7. **Contact Form with Mailto Dispatcher:** Client-side validated form that opens pre-populated email messages.
8. **WCAG 2.1 AA Compliant:** Accessible contrast ratios, focus rings, skip-to-content anchor, semantic HTML elements, and ARIA attributes.

## 🚀 How to Host on GitHub Pages (Free)

1. Initialize git in your local directory (if not already done):
   ```bash
   git init
   git add .
   git commit -m "Initial commit of personal developer portfolio"
   ```
2. Connect your GitHub repository:
   ```bash
   git remote add origin https://github.com/Swathi-Shetty37/Swathi-Shetty37.github.io.git
   git branch -M main
   git push -u origin main
   ```
3. In your GitHub repository settings, go to **Pages** > Select `main` branch > `/root` folder > Click **Save**.
4. Your website will be live at `https://swathi-shetty37.github.io/`!
